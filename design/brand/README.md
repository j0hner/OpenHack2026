# Loga Moje Sady

`moje-sady-light.svg` a `moje-sady-dark.svg` jsou nezměněné zdrojové soubory dodané uživatelem 14. listopadu 2026. Světlý zdroj obsahuje vložené PNG, tmavý zdroj vložené SVG.

Podle posledního zadání používá web v obou režimech bílé jablko se zeleným listem (`moje-sady-dark.svg`). Průhledný bezeztrátový export WebP v `src/assets/` je oříznutý pouze o prázdné průhledné okraje a zachovává poměr stran. Výška 320 px poskytuje rezervu pro displeje s vysokou hustotou. Samostatná PNG ikona má 64 × 64 px. Zdrojové SVG se do produkčního balíčku nenačítají.

Na mobilu má značka tmavě zelenou podložku, aby bílé jablko zůstalo viditelné i ve světlém záhlaví. Na desktopu stačí tmavé pozadí navigace.
